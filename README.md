# VisionGrade — ตรวจกระดาษคำตอบ Template No. 4 (เวอร์ชันหน้าเดียว)

เว็บหน้าเดียว ไม่ต้องล็อกอิน ไม่มีฐานข้อมูล และไม่ต้องติดตั้งอะไรเพิ่ม ทุกอย่างทำงานในเบราว์เซอร์

1. **ใส่เฉลยและคะแนนเต็ม** ของ Part 1 (60 ข้อ) และ Part 2 (10 ข้อ) โดยคลิกเลือก พิมพ์ต่อกัน หรืออ่านจากรูปกระดาษเฉลยก็ได้
   - มีข้อสอบหลายชุด: เลือก **จำนวนชุดข้อสอบ** (สูงสุด 3 ตามวง "ชุดกระดาษคำถาม") แล้วใส่เฉลย/คะแนนเต็มแยกแต่ละชุด ระบบจะตรวจแต่ละแผ่นด้วยเฉลยของชุดที่นักเรียนฝน ถ้านักเรียนไม่ได้ฝนชุด จะใช้ชุด 1 และขึ้นป้าย "ไม่รู้ชุด" ให้ครูเลือกชุดเองในหน้าต่าง ดู / แก้
2. **อัปโหลดรูปกระดาษคำตอบ** ได้หลายรูปพร้อมกัน (1 รูป = นักเรียน 1 คน)
3. **ดูผลคะแนน** รหัสนักเรียน รหัสวิชา รหัสสถานศึกษา ชุดข้อสอบ และคะแนนแยก Part 1 / Part 2 / รวม กด **ดู / แก้** เพื่อดูภาพที่มีกรอบเขียว/แดงและแก้คำตอบที่อ่านผิด แล้วกด **ส่งออกคะแนน** เลือกได้ 4 แบบ:
   - **Excel (.xlsx)** 3 แผ่นงาน: คะแนน, คำตอบรายข้อ, เฉลยแต่ละชุด
   - **CSV** เปิดได้ทุกโปรแกรม รวม Google Sheets
   - **PDF / พิมพ์** รายงานคะแนนพร้อมสถิติ (ค่าเฉลี่ย, SD, สูงสุด/ต่ำสุด) ในหน้าต่างพิมพ์ให้เลือก "บันทึกเป็น PDF"
   - **JSON** ข้อมูลครบ (คะแนน คำตอบ เฉลย) สำหรับนำไปใช้ต่อในโปรแกรมอื่น

## วิธีเปิด

ต้องเปิดผ่าน web server เพราะไฟล์ JavaScript เป็น ES module (ดับเบิลคลิก `index.html` ตรง ๆ จะใช้ไม่ได้)

**VS Code:** ติดตั้งส่วนเสริม *Live Server* แล้วคลิกขวาที่ `index.html` → *Open with Live Server*

**หรือใช้ Python:**
```bash
cd visiongrade-simple
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

ต้องต่ออินเทอร์เน็ตตอนเปิดครั้งแรก เพราะเว็บโหลด OpenCV.js และ ONNX Runtime Web จาก CDN

**นำขึ้นเว็บจริง (ฟรี):** อัปโหลดทั้งโฟลเดอร์นี้ขึ้น Cloudflare Pages, GitHub Pages หรือ Netlify (ลากโฟลเดอร์ไปวางได้เลย) ไม่ต้องมีขั้นตอน build

## โมเดล

- ยังไม่มีโมเดลก็ใช้ได้ วงกลมตรวจด้วยการวัดปริมาณหมึก แต่รหัสนักเรียนและ Part 2 จะเป็น `?` ให้กรอกเองในหน้าต่าง ดู / แก้
- เทรนเสร็จแล้วให้นำ `bubble.onnx` และ `digit.onnx` มาวางในโฟลเดอร์ `models/` ทำตาม **[docs/MODEL_TH.md](docs/MODEL_TH.md)** ได้ทีละขั้น
- (ไม่บังคับ) วาง `yolo.onnx` เพื่อให้ YOLO หามุมกระดาษก่อนปรับให้ตรง ถ้า YOLO หาพลาด เว็บจะกลับไปใช้ OpenCV ให้เอง

## การคิดคะแนน

- คะแนนต่อข้อ = คะแนนเต็มของ Part ÷ จำนวนข้อที่มีเฉลยใน Part นั้น
  - ตัวอย่าง: Part 1 มีเฉลย 60 ข้อ เต็ม 60 ได้ข้อละ 1 คะแนน
  - ตัวอย่าง: Part 2 มีเฉลย 10 ข้อ เต็ม 20 ได้ข้อละ 2 คะแนน
- ข้อที่ไม่ใส่เฉลยจะไม่นำมาคิดคะแนน
- ฝนเกิน 1 วงถือว่าผิด
- Part 2 ยอมให้คลาดเคลื่อนได้ตามค่า ± ที่ตั้งไว้
- แก้เฉลยหรือคะแนนเต็มเมื่อไร ผลของทุกแผ่นจะคิดใหม่ทันที
- **โหมดการตรวจ** (ตั้งในข้อ 1 ช่อง "โหมดการตรวจ")
  - **อัตโนมัติ** (ค่าเริ่มต้น): ตรวจเฉพาะส่วนที่นักเรียนทำ — ฝนตั้งแต่ 3 ข้อขึ้นไป = ทำข้อฝน (Part 1), เขียนตัวเลขตั้งแต่ 1 ข้อขึ้นไป = ทำข้อเขียน (Part 2) คะแนนเต็มของแผ่นคิดเฉพาะส่วนที่ทำ เช่น ฝนอย่างเดียวได้เต็ม 60, เขียนอย่างเดียวได้เต็ม 20 กระดาษเปล่าตรวจทุกส่วน (ได้ 0)
  - **ตรวจทุกส่วน** / **เฉพาะ Part 1 ข้อฝน** / **เฉพาะ Part 2 ข้อเขียน**: บังคับส่วนที่จะตรวจ
  - เปลี่ยนโหมดเฉพาะบางแผ่นได้ในหน้าต่าง **ดู / แก้** (ช่อง "โหมดตรวจแผ่นนี้")
  - ถ้าโหมดอัตโนมัติพบรอยฝนแค่ 1–2 ข้อ จะไม่ตรวจข้อฝน และขึ้นป้าย **ควรตรวจ** ให้ครูดูว่าเป็นรอยเปื้อนหรือนักเรียนทำจริง
  - คะแนนเต็มแต่ละแผ่นอาจไม่เท่ากัน สถิติรวม (เฉลี่ย / สูงสุด / ต่ำสุด) จึงแสดงเป็น % ส่วนเฉลี่ย Part 1 / Part 2 คิดเฉพาะแผ่นที่ตรวจส่วนนั้น

## ข้อควรรู้

- เฉลยจะถูกจำไว้ในเบราว์เซอร์ ส่วน**ผลตรวจจะหายเมื่อปิดหรือรีเฟรชหน้า** ให้กดส่งออกคะแนนก่อนปิด (ระบบจะเตือนให้)
- ไฟล์ Excel เก็บรหัสเป็นข้อความ เลข 0 ข้างหน้าไม่หาย ส่วนใน CSV รหัสเขียนเป็น `="..."` เพื่อไม่ให้ Excel ตัดเลข 0 ข้างหน้าทิ้ง
- รูปถ่ายต้องเห็นสี่เหลี่ยมดำที่มุมล่างทั้ง 2 อันและกล่องเลข "4" ที่มุมขวาบน ถ้าเห็นแค่ 2 อันล่าง ระบบจะประมาณตำแหน่งมุมบนให้ รูปไม่ควรเบลอและไม่ควรมีเงาบังช่องฝน
- ช่องรหัสนักเรียนบนกระดาษมี 14 ช่อง แต่รหัสจริงมี 13 หลัก ถ้าอ่านได้ไม่ครบ ระบบจะเตือนในรายการ "ควรตรวจด้วยตา"
