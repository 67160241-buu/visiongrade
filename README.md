# VisionGrade — ตรวจกระดาษคำตอบ Template No. 4 (เวอร์ชันหน้าเดียว)

เว็บหน้าเดียว ไม่ต้องล็อกอิน ไม่มีฐานข้อมูล และไม่ต้องติดตั้งอะไรเพิ่ม ทุกอย่างทำงานในเบราว์เซอร์

1. **ใส่เฉลยและคะแนนเต็ม** ของ Part 1 (60 ข้อ) และ Part 2 (10 ข้อ) โดยคลิกเลือก พิมพ์ต่อกัน หรืออ่านจากรูปกระดาษเฉลยก็ได้
2. **อัปโหลดรูปกระดาษคำตอบ** ได้หลายรูปพร้อมกัน (1 รูป = นักเรียน 1 คน)
3. **ดูผลคะแนน** แยก Part 1 / Part 2 / รวม กด **ดู / แก้** เพื่อดูภาพที่มีกรอบเขียว/แดงและแก้คำตอบที่อ่านผิด แล้ว **ดาวน์โหลด CSV**

## วิธีเปิด

ต้องเปิดผ่าน web server เพราะไฟล์ JavaScript เป็น ES module (ดับเบิลคลิก `index.html` ตรง ๆ จะใช้ไม่ได้)

**VS Code:** ติดตั้งส่วนเสริม *Live Server* แล้วคลิกขวาที่ `index.html` → *Open with Live Server*

**หรือใช้ Python:**
```bash
cd visiongrade-simple
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

ต้องต่ออินเทอร์เน็ตตอนเปิดครั้งแรก เพราะเว็บโหลด OpenCV.js และ ONNX Runtime Web จาก CDN

**นำขึ้นเว็บจริง (ฟรี):** อัปโหลดทั้งโฟลเดอร์นี้ขึ้น Cloudflare Pages, GitHub Pages หรือ Netlify (ลากโฟลเดอร์ไปวางได้เลย) ไม่ต้องมีขั้นตอน build

## โมเดล

- ยังไม่มีโมเดลก็ใช้ได้ วงกลมตรวจด้วยการวัดปริมาณหมึก แต่รหัสนักเรียนและ Part 2 จะเป็น `?` ให้กรอกเองในหน้าต่าง ดู / แก้
- เทรนเสร็จแล้วให้นำ `bubble.onnx` และ `digit.onnx` มาวางในโฟลเดอร์ `models/` ทำตาม **[docs/MODEL_TH.md](docs/MODEL_TH.md)** ได้ทีละขั้น

## ไฟล์ในโปรเจกต์

```
visiongrade-simple/
├── index.html            หน้าเว็บ (หน้าเดียว)
├── css/style.css
├── js/

│   ├── cv-pipeline.js    อ่านกระดาษ: หา marker → ปรับภาพให้ตรง → ตัดช่อง → runInference() → คำตอบ

├── tools/verify_onnx.py  ตรวจไฟล์ ONNX ก่อนนำมาใช้

```

## การคิดคะแนน

- คะแนนต่อข้อ = คะแนนเต็มของ Part ÷ จำนวนข้อที่มีเฉลยใน Part นั้น
  - ตัวอย่าง: Part 1 มีเฉลย 60 ข้อ เต็ม 60 ได้ข้อละ 1 คะแนน
  - ตัวอย่าง: Part 2 มีเฉลย 10 ข้อ เต็ม 20 ได้ข้อละ 2 คะแนน
- ข้อที่ไม่ใส่เฉลยจะไม่นำมาคิดคะแนน
- ฝนเกิน 1 วงถือว่าผิด
- Part 2 ยอมให้คลาดเคลื่อนได้ตามค่า ± ที่ตั้งไว้
- แก้เฉลยหรือคะแนนเต็มเมื่อไร ผลของทุกแผ่นจะคิดใหม่ทันที

## ข้อควรรู้

- เฉลยจะถูกจำไว้ในเบราว์เซอร์ ส่วน**ผลตรวจจะหายเมื่อปิดหรือรีเฟรชหน้า** ให้ดาวน์โหลด CSV ก่อนปิด (ระบบจะเตือนให้)
- ใน CSV รหัสนักเรียนเขียนเป็น `="..."` เพื่อไม่ให้ Excel ตัดเลข 0 ข้างหน้าทิ้ง
- รูปถ่ายต้องเห็นสี่เหลี่ยมดำที่มุมล่างทั้ง 2 อันและกล่องเลข "4" ที่มุมขวาบน ถ้าเห็นแค่ 2 อันล่าง ระบบจะประมาณตำแหน่งมุมบนให้ รูปไม่ควรเบลอและไม่ควรมีเงาบังช่องฝน
- ช่องรหัสนักเรียนบนกระดาษมี 14 ช่อง แต่รหัสจริงมี 13 หลัก ถ้าอ่านได้ไม่ครบ ระบบจะเตือนในรายการ "ควรตรวจด้วยตา"
